# 🎉 KIADISSA

Party game multijoueur en ligne entre potes (3 à 12 joueurs) : anecdotes anonymes à deviner, votes « qui est le plus… », questions oui/non anonymes et mode 🔥 Hot (18+).

Le code du jeu est dans le dossier [`qui-a-dit-ca/`](qui-a-dit-ca/). Son [README](qui-a-dit-ca/README.md) détaille les règles, comment lancer le jeu en local et comment le mettre en ligne sur Render.
