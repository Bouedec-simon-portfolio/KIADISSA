# 🎉 KIADISSA

Party game multijoueur en ligne entre potes (3 à 12 joueurs) : 8 types de manches (anecdotes, menteur, qui est le plus…, oui/non, tu préfères, complète la phrase, je n'ai jamais, qui me connaît), réactions en direct, joker, packs de questions dont un mode 🔥 Hot (18+).

Le code du jeu est dans le dossier [`qui-a-dit-ca/`](qui-a-dit-ca/). Son [README](qui-a-dit-ca/README.md) détaille les règles, comment lancer le jeu en local et comment le mettre en ligne sur Render.
